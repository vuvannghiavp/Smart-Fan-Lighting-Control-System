# Smart Fan Lighting Control System (Platform Arduino)
An IoT-based smart home system that monitors environmental conditions and controls fan and lighting devices using NRF24L01 wireless communication.
# Features
- Temperature and humidity monitor
- Use the LDR and DHT22 sensor
- Wireless communication using nRF24n01
- Automatic or manual fan, led control
- LCD display
# Systerm architecture
# Hardware
- Arduino Uno
- NRF24L01
- LDR
- DHT22
- LCD 16x2 I2C
- L298N
